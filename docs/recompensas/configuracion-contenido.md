# Configuración de Contenido de Recompensas

## Tipos de contenido

Una Recompensa se puede configurar con:

| Tipo | Formato |
|---|---|
| **Imagen** | JPG / PNG / GIF |
| **Vídeo** | MP4 |
| **Audio** | MP3 |

## Código Único

Se puede generar un **Código Único** por Recompensa, útil para controlar unidades entregadas en el mundo real (a nivel analógico).

## Traducciones

Funciona igual que cualquier caja de contenido: soporta hasta **10 idiomas** simultáneos.

## Acciones

- **Guardar**: Guarda la configuración.
- **Eliminar**: Elimina la Recompensa.
- **Atrás**: Vuelve al listado de Recompensas.
