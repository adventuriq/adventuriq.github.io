# Enlazar Retos a una Misión

## Gestión de Retos

![Enlazar retos a misiones desde el panel de administración](/img/img-060.png)


Normalmente los Retos se crean a **Nivel Aventura** y se enlazan a **Nivel Misión**.

| Acción | Descripción |
|---|---|
| **Enlazar Reto** | Asocia un Reto existente a esta Misión |
| **Crear nuevo Reto** | Atajo para crear un Reto nuevo directamente |
| **Desenlazar Reto** | Desvincula un Reto de la Misión (no lo elimina) |
| **Editar Reto** | Haz clic sobre el nombre del Reto para editarlo |

## Orden de los Retos

- Se puede **ordenar** cómo se visualizan los Retos dentro de una Misión.
- Usa **"Es Inicio"** y **"Es Fin"** para mostrar banderitas sobre los Mapas Geolocalizados.
- **Guarda Relaciones y Orden** con el botón correspondiente.
