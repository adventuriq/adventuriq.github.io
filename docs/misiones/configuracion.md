# Configuración de una Misión

Las Misiones tienen como función **organizar los Retos** de una Aventura.

## Características principales

![Cabecera de Misión 1 - ejemplo de diseño](/img/img-085.png)


- El Game Designer usa las Misiones según el diseño de su juego, decidiendo si el acceso está bloqueado, si es visible inicialmente, qué Retos componen la Misión y si entrega Objetos al final.
- Las Misiones son vitales para la **organización narrativa** de una Aventura. Las podemos usar como **Capítulos, Etapas, Temporadas, Fases, Niveles**, etc.
- Usar bloqueos para acceder a una Misión nos permite controlar los **"Tempos" de juego**.

## Panel del listado de Misiones

![Panel de configuración de misiones en el Gamifier](/img/img-060.png)


| Elemento | Descripción |
|---|---|
| **Nombre de la Misión** | Nombre y acceso a su edición |
| **ID de la Misión** | Importante para las Condiciones de Final de Aventura |
| **Número de Retos** | Retos que componen cada Misión |
| **Fecha de creación** | Fecha de creación y última modificación |
| **Crear nueva Misión** | Botón para crear una nueva Misión |
| **Eliminar Misión** | No elimina los Retos que contiene, solo los desenlaza |
| **Ordenar** | Se puede ordenar la visualización de las Misiones en la Web App |

## Componente Mapa

![Cabecera de Misión 2 - ejemplo de diseño](/img/img-088.png)


El Componente Mapa de una Misión puede ser:
- Una **Imagen**
- Un **Mapa Google Maps** con una posición Lat/Long
- Un **conjunto de posiciones Lat/Long** heredadas de los Retos que componen la Misión
