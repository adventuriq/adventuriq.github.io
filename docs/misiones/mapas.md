# Mapas de una Misión

El componente Mapa de una Misión funciona igual que a nivel Aventura.

## Tipos de mapa



- **Recurso Gráfico**: imagen que puede servir como pista, enigma, etc.
- **Mapa Google Maps**: con geoposición Lat/Long.

## Restricciones

- A nivel Aventura y Misión, los Mapas **no se pueden bloquear** por Códigos Alfanuméricos ni Códigos QR (esta funcionalidad solo está disponible a nivel Reto).
- Se tiene que crear el Recurso Mapa aunque no se use como un mapa.
