# Descripción de una Misión

La Descripción de una Misión funciona de manera muy parecida a la Descripción de una Aventura.

## Traducciones

![Descripción de misión vista desde la app del jugador](/img/img-064.png)


- Se puede eliminar una traducción seleccionada con el botón correspondiente.
- El funcionamiento es idéntico al de cualquier caja de contenido multiidioma.

## Acciones

- **Botón Guardar**: Guarda la configuración de la Misión.
- **Botón Eliminar Misión**: No se eliminan los Retos enlazados a esa Misión, solo se desenlaza la relación.
