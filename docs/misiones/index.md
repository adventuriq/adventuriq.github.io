# 📋 Misiones

Las **Misiones** son el nivel intermedio en la jerarquía de AdventuriQ: **Aventura → Misión → Reto**. Cada Aventura contiene una o varias Misiones, y cada Misión agrupa uno o varios Retos. El Game Master utiliza las Misiones para organizar la experiencia del Player en bloques temáticos, secuenciales o paralelos — como capítulos de un libro o niveles de un videojuego.

Una Misión define **qué Retos** ve el Player, **cuándo** los puede jugar (bloqueos temporales, códigos de acceso), **dónde** se ubican (mapas), **qué recibe** al completarlos (Objetos Digitales) y **cuándo se considera finalizada** (condiciones configurables). Todo se gestiona desde una única página de edición en el Gamifier.

## Antes de empezar

Para trabajar con Misiones necesitas tener al menos una **Aventura creada**. Las Misiones se crean y configuran dentro de una Aventura desde el Gamifier.

:::tip
Si es la primera vez que usas AdventuriQ, empieza por [Crear una Aventura](../aventuras/crear-aventura.md) y luego vuelve aquí para aprender a estructurarla con Misiones.
:::
