# Métricas - Vista Game Board

## Descripción

El **Game Board** ofrece una vista basada en los **Retos** que componen la Aventura. Permite un acceso rápido a cada Reto y ver cómo se comportan los jugadores hasta ese momento.

## Características

- Información en **tiempo real** (refrescar para actualizar).
- Información **descargable** en formato tabulado.
- Vista detallada del progreso por Reto.
- Visualización de respuestas en Retos de Respuesta Libre.
