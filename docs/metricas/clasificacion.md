# Métricas - Vista Clasificación

## Acceso



Desde la Configuración de una Aventura, se puede acceder a las **dos vistas** sobre las Métricas del juego: Clasificación y Game Board.

## Herramientas

| Botón | Función |
|---|---|
| **Raze** | Elimina todos los estados de juego. ¡No hay vuelta atrás! |
| **Eliminar mis jugadas** | Permite rejugar la Aventura por parte del Game Master/Designer |
| **Eliminar mis recompensas** | Limpia las recompensas del administrador |
| **Top Ten** | Publica una URL con el Ranking Top 10 del juego |

:::danger Raze
Es recomendable **descargar las Métricas** antes de hacer un Raze si hay datos de juego real. Es útil para hacer un Reset del juego o durante el testeo.
:::

## Vista Clasificación

Es una vista basada en los **jugadores**. Un listado ordenado de las Métricas por jugador.

- Información en **tiempo real** (refrescar la página para actualizar).
- Información **descargable** en formato tabulado.
- Botón de **Raze individual** para eliminar los estados de juego de un jugador específico.
