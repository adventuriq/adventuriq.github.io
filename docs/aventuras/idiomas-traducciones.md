# Idiomas y Traducciones

## Contenido multiidioma

![Sección de idiomas y traducciones en el editor de aventura](/img/img-061.png)


Los iconos de idiomas identifican los contenidos mostrados en la Web App. El jugador puede seleccionar el idioma con el que quiere jugar desde el menú **"Perfil"**, siempre que la Aventura tenga el contenido traducido.

### Agregar traducciones

- Donde aparezca el botón **"+ Nueva Traducción"**, se puede incorporar contenido en los idiomas seleccionados para la Aventura.
- Se pueden configurar hasta **10 idiomas diferentes** en el contenido HTML enriquecido (con opciones de negritas, subrayado, colores, iFrames, etc.).

:::info
A diferencia de las imágenes (que no tienen opciones por idiomas), el contenido textual sí permite múltiples traducciones.
:::

### Longitud de campos

Los campos donde se puede introducir texto tienen **longitudes variables** en cuanto a la cantidad de caracteres. Siempre se ha de validar en la Web App cómo quedan los contenidos, ya que según el dispositivo pueden quedar cortados.

### Menú de idiomas

Se dispone de un **menú desplegable** donde seleccionar el idioma con el que se quiere leer los contenidos del juego.
