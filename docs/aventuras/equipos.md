# Equipos (Clanes)

Las Aventuras pueden ser jugadas de dos maneras: **Individual** o **Por Equipos**.

## Juego por Equipos

![Concepto de equipos - juego de mesa colaborativo](/img/img-231.png)


En el juego Por Equipos:

- La **Puntuación Individual** de un jugador se suma a la **Puntuación del Equipo**.
- En la vista Clasificación aparecen dos nuevos elementos:
  - **Clasificación dentro del Equipo**
  - **Clasificación Global por Equipos**

## Configuración de un Equipo (Clan)

![Configuración de equipos en el panel de administración](/img/img-060.png)


| Campo | Descripción |
|---|---|
| **Nombre del Equipo** | Nombre visible del Clan |
| **Descripción del Equipo** | No se visualiza en la Web App, sirve para Storytelling |
| **Icono del Equipo** | Imagen representativa del Clan |

## Gestión de miembros

- Para poder añadir un jugador al Clan, este jugador **debe haber empezado a jugar** la Aventura.
- Se pueden **desvincular** miembros del Equipo.
- Botón para **guardar** la configuración del Equipo.
- Botón para **eliminar** el Equipo.
