# Retos de la Aventura

## Listado de Retos

El listado muestra todos los **Retos creados para esta Aventura**. Para que un Reto sea jugable, debe **enlazarse dentro de una Misión**.

:::info
Aunque un Reto esté enlazado a más de una Misión, **solo se ejecutará una vez**.
:::

## Crear y editar Retos

- Usa el botón **"Crear nuevo Reto"** para añadir retos a la Aventura.
- Haz clic sobre el **nombre del Reto** para editarlo.

## Retos sin Misión

Un Reto sin Misión Asociada mostrará un icono de advertencia. Esto significa que el Reto **no será jugable**, ya que no se podrá tener acceso a él.

:::tip
No es ningún problema tener retos sin misión. Esta zona se usa como una **gran bolsa de Retos**, usados y sin usar. Es el diseñador de la Aventura quien decidirá qué retos usar de los que haya creado.
:::

## 5 Tipos de Retos

Existen **5 tipos de Retos** completamente configurables, para usar en una Aventura tantas veces como sea necesario:

1. **Pregunta / Respuesta(s)**
2. **Preguntas Encadenadas**
3. **Respuesta Libre**
4. **Llamada a la Acción**
5. **Compartir Foto**
