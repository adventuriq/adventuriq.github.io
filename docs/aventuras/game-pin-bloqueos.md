# Game Pin y Bloqueos

## Game Pin



El **Game Pin** es el número que se genera automáticamente una vez se crea la Aventura. Es el código que los jugadores usan para cargar la Aventura en la Web App.

## Códigos de bloqueo

El código de bloqueo a la Aventura puede ser un **código alfanumérico** (números y letras) que permite bloquear la Aventura una vez esté publicada.

### Códigos QR

- El sistema genera automáticamente los **códigos QR** a partir de los códigos alfanuméricos que se introducen.
- Para generar más de un QR, hay que introducir un nuevo código en una línea aparte.
- La Web App incorpora un **lector de códigos QR** integrado.

:::tip Consejo
Puedes usar códigos QR para controlar el acceso a la Aventura, creando experiencias más inmersivas donde los jugadores deben encontrar físicamente el código para desbloquear el contenido.
:::
