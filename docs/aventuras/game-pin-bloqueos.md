# Game Pin y Bloqueos

## Game Pin



El **Game Pin** es el número que se genera automáticamente una vez se crea la Aventura. Es el código que los jugadores usan para cargar la Aventura en la Web App.

Lo tienes siempre a mano en el **listado de Aventuras** del Gamifier: cada Aventura muestra en su propia fila el **GamePIN** y la tarjeta **Acceso directo a la Aventura** con el enlace para jugar, un botón para copiarlo y otro para **descargar su QR listo para imprimir** (ver [Acceder a una Aventura](acceder-a-una-aventura.md#copiar-el-enlace-o-descargar-el-qr-desde-el-listado-de-aventuras)). En la ficha de la Aventura los encontrarás también en el apartado **Acceso a la Aventura**, junto al código QR.

## Códigos de bloqueo

El código de bloqueo a la Aventura puede ser un **código alfanumérico** (números y letras) que permite bloquear la Aventura una vez esté publicada.

### Códigos QR

- El sistema genera automáticamente los **códigos QR** a partir de los códigos alfanuméricos que se introducen.
- Para generar más de un QR, hay que introducir un nuevo código en una línea aparte.
- La Web App incorpora un **lector de códigos QR** integrado.

:::tip Consejo
Puedes usar códigos QR para controlar el acceso a la Aventura, creando experiencias más inmersivas donde los jugadores deben encontrar físicamente el código para desbloquear el contenido.
:::

:::info Los bloqueos no evitan el consumo de Tokens
Un Player que entra por **código de acceso o QR** consume **1 Token** la primera vez que empieza a jugar, igual que cualquier otro Player. Consulta [Tokens y Licencias](/tokens).
:::
