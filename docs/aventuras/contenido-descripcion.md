# Contenido y Descripción

## Campos principales



| Campo | Descripción |
|---|---|
| **Título Aventura** | Nombre de la Aventura |
| **Resumen Aventura** | Texto corto visible en el listado |
| **Descripción** | Descripción visible en la Web App |
| **Descripción Extendida** | Descripción detallada visible en la Web App |
| **Mensaje Final Aventura** | Texto que se muestra al finalizar |
| **Fechas/Horas Inicio/Fin** | Programación automática de la Aventura |

## Editor de contenido



- El contenido HTML enriquecido permite opciones de configuración tipo **Negritas, Subrayado, Colores, iFrames**, etc.
- Se pueden incorporar hasta **10 idiomas diferentes**.
- Todas las cajas de Descripción permiten su configuración en **HTML** y la incrustación de **iFrames** (como YouTube).

## Acciones

- **Botón Guardar**: Guarda la configuración de la Aventura.
- **Botón Eliminar**: Elimina una Aventura completamente.
- Acceso al **Menú Bitácora** desde la configuración.
