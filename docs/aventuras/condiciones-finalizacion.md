# Condiciones de Finalización

## Comportamiento por defecto

![Configuración de condiciones de finalización en el Gamifier](/img/img-060.png)


Si no se selecciona ninguna condición concreta, la Aventura **finaliza una vez se finalizan todas las Misiones** que la componen.

## Condiciones automáticas

La Aventura puede finalizar automáticamente según **seis tipos de condiciones posibles**. Se puede programar más de una condición para que una Aventura finalice automáticamente.

:::warning
A la que se cumpla **una** de las condiciones programadas, la Aventura finaliza automáticamente.
:::

## Configuración

- Selecciona el **tipo de condición** de finalización.
- Introduce el **valor** correspondiente según la condición seleccionada.
- Usa el botón **"+"** para añadir una nueva condición.
- Usa el botón **eliminar** para borrar una condición ya programada.
- **Guarda** todas las modificaciones sobre las Condiciones de Finalización.
