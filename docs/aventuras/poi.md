# Puntos de Interés (POI)

## ¿Qué es un POI?



Un **POI** (Point of Interest) es información de interés que aparece en un Mapa Geolocalizado, pero **sin interacción** con el jugador.

## Características



Comparte con el resto de elementos de una Aventura la opción de customizar:

- **Título**
- **Descripción**
- **Imagen**
- **Mapa Geolocalizado**

## Gestión

- Para editar un POI ya creado, haz clic sobre el **nombre del POI**.
- Se pueden crear tantos POIs como sean necesarios para enriquecer la experiencia del mapa.
