# Recompensas a Nivel de Reto

Las Recompensas a Nivel de Reto se diferencian de las de Nivel Misión en que son **configurables** (condiciones de entrega) y **no tienen la opción de "Llamada"**.

## Condiciones de entrega

Las opciones disponibles para la configuración de entrega son múltiples:

| Condición | Descripción |
|---|---|
| **Siempre** | Activa por defecto, se entrega siempre |
| **Nunca** | Desactiva la Recompensa sin borrarla del sistema |
| **Dar un máximo de n** | Limita el número de entregas (ej: solo 10 camisetas) |
| **Otras condiciones** | Basadas en el resultado del Reto |

:::info
Solo que se cumpla **una** de las condiciones configuradas, ya se entrega la Recompensa (igual que las Condiciones de final de Aventura).
:::

## Configuración

- Se configuran igual que una Recompensa a Nivel de Misión.
- Introduce el **valor** según la condición seleccionada.
- Usa el botón **"+"** para añadir nuevas condiciones.
- **Guarda** siempre las modificaciones de manera manual.
