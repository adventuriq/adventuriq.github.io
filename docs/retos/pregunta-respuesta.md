# Reto tipo Pregunta / Respuesta(s)

## Puntuación

- **Puntos si se acierta**: los puntos otorgados pueden ser negativos.
- **Puntos si se falla**: también pueden ser negativos.

## Configuración de respuestas

- Se puede añadir **tantas respuestas como se quiera**.
- Se seleccionan las **respuestas correctas** (pueden ser una, más de una, o incluso todas).
- **Es Multirespuesta**: si queremos que el jugador seleccione "Todas" las correctas, hay que activar este control.

## Opciones especiales

| Opción | Uso |
|---|---|
| **Mostrar respuesta correcta** | Para proyectos educativos, donde el jugador "se lleva" la respuesta correcta |
| **Todas correctas** | Para Aventuras narrativas, donde todas las opciones son válidas |
| **Multirespuesta** | El jugador debe seleccionar todas las respuestas correctas |

## Imagen de la mecánica

- Se puede asignar una imagen de **1200x640 pixels** visible en la mecánica del Reto.
- Puede ser **diferente** a la imagen de la cabecera del Reto.

## Enunciado y respuestas

- El enunciado de la pregunta se introduce en el idioma seleccionado.
- Los **identificadores de respuesta** se usan en las Métricas para controlar qué respuestas seleccionan los jugadores y para entregar recompensas basadas en IDs de Respuestas.

## Límite de tiempo

Este tipo de Reto permite configurar una **cuenta atrás** para la ejecución.

:::warning
Eliminar Mecánicas las elimina **definitivamente** del sistema (incluidas las vinculadas a una Misión).
:::
