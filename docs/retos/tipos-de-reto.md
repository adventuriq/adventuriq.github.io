# Tipos de Reto

Existen **5 tipos de Retos** completamente configurables, para usar en una Aventura tantas veces como sea necesario.

## Resumen de tipos

| Tipo | Descripción | Uso principal |
|---|---|---|
| **Pregunta / Respuesta(s)** | Preguntas con una o múltiples respuestas correctas | Quiz, evaluación, trivia |
| **Preguntas Encadenadas** | Saco de preguntas P/R entregadas continuamente | Rondas rápidas, exámenes |
| **Respuesta Libre** | El jugador escribe libremente su respuesta | Creatividad, reflexión |
| **Llamada a la Acción** | Instrucciones para hacer algo fuera de AdventuriQ | Actividades analógicas |
| **Compartir Foto** | Tomar o cargar una foto y compartirla | Creatividad visual, pruebas |

## Mecánicas de juego

Los Retos son las **mecánicas de juego** que AdventuriQ pone a disposición para construir la dinámica del juego. Son los momentos donde el sistema puede:

- **Otorgar puntos** (visibles para el jugador o solo en Métricas).
- **Entregar Recompensas** (Objetos configurables).

## Estructura de un Reto

Todos los Retos comparten una estructura definida:

1. **Cabecera**: configuración común (título, descripción, imágenes, audio)
2. **Mapa**: Imagen o Google Maps
3. **Recompensas**: opcional
4. **Mecánica específica**: configuración propia de cada tipo de Reto
